# OpenChain Southeast Asia Work Group

Welcome to Southeast Asia!

OpenChain Southeast Asia Work Group, a subgroup of the Linux Foundation [OpenChain Project](https://www.openchainproject.org/), aims to Build an inclusive regional network connecting individuals, communities, and organizations to strengthen open source governance, compliance, and software supply chains.

## Objectives

- Foster regional collaboration in open source governance, compliance, security, and supply chains.
- Share practical experience and good practices across the region.
- Connect regional participants with the global OpenChain community.
- Explore emerging topics across open source and AI supply chains.
